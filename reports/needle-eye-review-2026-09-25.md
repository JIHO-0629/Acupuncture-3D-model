# Needle’s Eye 재검증 보고서 — 2026-09-25

## 결론

- 전체 361개 경혈 가운데 **122개(33.8%)**만 Needle’s Eye 대상으로 선별했다.
- 선별 기준은 흉막·허파, 주요 동맥·정맥, 주요 말초신경·신경얼기, 척수·숨뇌, 심장·기관이다.
- 총 169개 구조는 경계 48, 동맥 44, 정맥 17, 신경 60개다.
- 카메라 회전과 무관한 해부학 기준 방위를 사용한다. 실제 모델 경로가 구조를 관통한 경우에만 중심축에 `경로 교차`로 표시한다.
- 문헌의 단일 mm 값은 개인별 확정 깊이 또는 안전거리로 사용하지 않는다. 문헌 구조는 `문헌 근거 · 개인차 큼`, 모델 구조만 `참조 모델 해당 깊이`로 구분한다.

## 데이터 선별 규칙

1. 로컬 경혈별 자침 경로와 `needling-path-review-2026-09-24.csv`의 5 mm 이내 구조를 합친다.
2. 흉막·허파, 대혈관, 주요 신경, 척수·숨뇌, 심장·기관만 통과시킨다.
3. 구조의 모델 메시를 확인할 수 있는 경우에만 해부학 좌표계의 상대방위를 계산한다.
4. 문헌에만 있는 구조는 위치를 지어내지 않고 목록에만 남긴다.
5. 원의 링은 mm 눈금이 아닌 상대 거리 구역으로 표시한다.
6. 현 깊이와 가까운 구조만 진하게 표시하고, 먼 구조는 흐리거나 숨긴다.

## 이번에 교정한 항목

- **GB34:** 온종아리신경을 대표 위험구조로 추가했다. 오금동·정맥은 모델상 자침 상한보다 깊다는 상태를 유지했다.
- **ST36:** 오금동맥 대신 앞정강동맥과 깊은종아리신경을 대표 구조로 교정했다.
- **SP6:** 뒤정강동맥과 정강신경을 추가했다.
- **BL40:** 얕은 쪽부터 정강신경 → 오금정맥 → 오금동맥이라는 실제 해부 관계를 명시하고, 참조 모델의 깊이·순서 차이를 경고했다.
- **깊이 연동:** 슬라이더의 0–100% 값을 mm로 오인하던 경로를 제거하고, 각 혈자리의 `modelMaxMm`로 환산한다.
- **문헌값:** GB20, GB21, LI18, ST9의 단일 문헌 깊이는 데이터에 참고값으로 보존하되, UI 위치·안전거리 계산에는 사용하지 않는다.
