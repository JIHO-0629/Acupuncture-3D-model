# Needle’s-eye Compass — 별도 시안

기존 자침 시뮬레이터 파일을 수정하지 않고 만든 독립 HTML 시안입니다.

## 핵심 결정

- 기존 세로 `Needling Profile`의 층서·깊이 조작은 그대로 유지합니다.
- `주변 구조만 (3)`을 누르면 오른쪽 보조 뷰가 열리는 구조입니다.
- 원의 중심은 침 축이며 `앞 ↑ · 가쪽 →` 방향은 모델 카메라와 무관하게 고정합니다.
- 신경·혈관은 빈 윤곽선, 막·장기 표면은 arc/band로 구분합니다.
- 현재 바늘 끝과 같은 단면은 진하게, 약간 위·아래는 흐리게, 멀면 사실상 숨깁니다.
- 중심선이 실제로 구조를 관통할 때만 `경로 교차`를 표시합니다.

## mm를 확정할 수 없는 경우

기본값은 **비척도(relative, not-to-scale)** 입니다. 따라서 5 mm / 10 mm 숫자를 그리지 않고 `축 근처`와 `주변 시야`만 표시합니다. 구조 설명도 `같은 단면`, `약간 위`, `약간 아래`, `현재 단면 밖`으로 제한합니다.

향후 다음 두 조건을 모두 만족할 때만 mm를 활성화합니다.

1. 모델의 월드 좌표와 실제 길이 단위 사이의 스케일이 검증됨
2. 해당 구조의 segmentation/registration 오차 범위를 함께 산출할 수 있음

활성화 이후에도 `3.0 mm` 같은 단일 소수점 수치보다는 `모델 추정 ≈ 3–5 mm`처럼 범위와 근사 기호를 함께 표시합니다. 이 수치는 `안전거리`가 아니라 `참조 모델상 측방 거리`로 명명합니다.

## 확인 방법

`index.html`을 브라우저에서 열고 세로 프로파일을 드래그하거나 방향키로 이동합니다. 구조물의 농도와 단면 상태가 현재 깊이에 맞춰 변합니다.
