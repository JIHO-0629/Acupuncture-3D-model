# 전체 배치 시안 3종

현재 앱 파일을 수정하지 않은 독립 비교 시안입니다. `index.html`에서 상단 비교 스위처로 세 레이아웃을 즉시 전환할 수 있습니다.

## 1. 이미지 중시형

- 3D 캔버스를 가장 크게 유지합니다.
- 자침 프로파일과 Needle's-eye Compass를 캔버스 하단의 분석 도크로 배치합니다.
- 학습 메모는 현재 3D 장면에 붙는 작은 공간 메모로 배치합니다.
- 모델을 돌려가며 관찰하고 짧은 메모를 남기는 사용에 적합합니다.

## 2. 정보 중시형

- 3D 모델은 왼쪽 참조 뷰로 축소합니다.
- 위치, 자침법, 자침 프로파일, 원형 단면, 근거를 넓은 학습 문서 영역에 배치합니다.
- 학습 메모는 우측 전체 높이의 독립 열을 사용합니다.
- 자료 비교와 장문 메모에 가장 적합하지만 3D 몰입감은 가장 낮습니다.

## 3. 균형안

- 화면을 54:46으로 나누어 3D 모델과 학습 정보를 동시에 유지합니다.
- 위치와 자침법은 상단, 종단면과 횡단면은 중앙에 나란히 배치합니다.
- 학습 메모는 하단에 항상 보이되 분석 화면을 밀어내지 않는 높이로 고정합니다.
- 일반적인 탐색, 자침 학습, 메모를 오가는 기본안으로 권장합니다.

## 유지한 조건

- 기존 기능과 버튼을 삭제하지 않았습니다.
- 앱 글꼴 계열을 변경하지 않았습니다.
- 문구와 자침 정보의 의미를 변경하지 않았습니다.
- 학습 메모는 혈자리별 자동 저장을 전제로 하며 별도의 저장 버튼을 추가하지 않았습니다.
